1. Estructura básica de un documento

Toda página web comienza con esta plantilla. Guárdala como archivo index.html y ábrela en el navegador:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Mi página</title>
</head>
<body>
    <h1>Hola, mundo</h1>
    <p>Mi primera página web.</p>
</body>
</html>
PartePara qué sirve
<!DOCTYPE html>Indica al navegador que es un documento HTML5. Sin él, el navegador puede interpretar la página en modo antiguo.
<html lang="es">Es la raíz del documento. El atributo lang indica el idioma (importante para accesibilidad y traducción automática).
<head>Información no visible: codificación, título, hoja de estilos, favicon...
<meta charset="UTF-8">Codificación de caracteres: permite tildes, eñes y emojis.
<meta name="viewport">Hace que la página se adapte a móvil (diseño responsive).
<title>Texto que aparece en la pestaña del navegador y en los buscadores.
<body>Todo el contenido visible de la página va dentro de aquí.

Dato curioso: desde HTML5 ya no hace falta cerrar algunas etiquetas (por ejemplo <meta> o <li>), pero se recomienda siempre cerrar las que lo admiten, como <p> o <div>.

2. Encabezados y párrafos

Los encabezados van de <h1> (el más importante) a <h6>. Debe haber un solo <h1> por página y no se debe saltar de nivel (de <h2> a <h4>, por ejemplo). El texto de los párrafos va dentro de <p>.

Enlaces <a>

<a href="pagina2.html">Otra página de mi web</a>
<a href="mailto:alumno@ejemplo.com">Enviar un correo</a>
<a href="#seccion">Ir a una sección de esta misma página</a>

<a href="https://example.com" target="_blank" rel="noopener">
    Abrir en pestaña nueva
</a>
Ejemplo renderizado

Visitar MDN · Enviar un correo

href es el destino; si empieza por http es externa y si no, es relativa a tu proyecto. El atributo target="_blank" abre en pestaña nueva (acompañado siempre de rel="noopener" por seguridad).

Imágenes <img>

<img src="foto.jpg" alt="Descripción de la foto" width="400">

Es una etiqueta vacía (no se cierra). El atributo alt es obligatorio en la práctica: describe la imagen para lectores de pantalla, si el archivo falla o para SEO. El formato moderno recomendado para fotos es webp y para iconos o logos con transparencia, svg.

5. Elementos semánticos

Un elemento es semántico cuando su nombre indica para qué se usa. Antes de HTML5 todo se colocaba dentro de <div> (que no significa nada). Usar etiquetas semánticas hace el código más claro y mejora la accesibilidad y el posicionamiento en buscadores (SEO).

EtiquetaSignificado
<header>Cabecera de la página o de una sección (título, logo, menú).
<nav>Bloque de navegación con enlaces.
<main>Contenido principal de la página. Solo puede haber uno y sin repetirse en el resto del sitio.
<section>Agrupación temática de contenido, normalmente con su propio encabezado.
<article>Contenido independiente y reutilizable: una noticia, una entrada de blog, una tarjeta...
<aside>Contenido secundario o relacionado (barra lateral, tips, publicidad).
<footer>Pie: copyright, enlaces legales, contacto.
<div>Sin significado: contenedor para maquetar con CSS. Úsalo solo si ninguna etiqueta semántica encaja.
<span>Como div, pero en línea (dentro de un párrafo) para aplicar estilo a un fragmento de texto.

Esqueleto típico de una página con estos elementos:

<body>
    <header>
        <h1>Mi web</h1>
        <nav>
            <a href="/">Inicio</a>
            <a href="/noticias">Noticias</a>
        </nav>
    </header>

    <main>
        <article>
            <h2>Título de la noticia</h2>
            <p>Texto del artículo...</p>
        </article>

        <aside>
            <p>Dato relacionado o enlace recomendado.</p>
        </aside>
    </main>

    <footer>
        <p>&copy; 2026 Mi web</p>
    </footer>
</body>

Regla de oro: section agrupa contenido relacionado; article es contenido que tendría sentido por sí solo. Si tienes duda entre div y una etiqueta semántica, elige la semántica.

6. Listas

Lista no ordenada <ul>

Para elementos sin un orden concreto (menús, listado de características).

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Lista ordenada <ol>

Para pasos o elementos con orden. Con start se indica el número inicial y con type el tipo de numeración.

<ol start="1">
    <li>Instala el editor.</li>
    <li>Crea el archivo HTML.</li>
    <li>Ábrelo en el navegador.</li>
</ol>

Para pares de término (<dt>) y descripción (<dd>):

    <dd>Apariencia del contenido.</dd>
</dl>

7. Tablas

Las tablas sirven para mostrar datos tabulares. Estructura: <table> contiene filas <tr>; dentro de cada fila, celdas de cabecera <th> o de datos <td>. <thead>, <tbody> y <tfoot> agrupan las filas y <caption> pone el título de la tabla.

<table>
    <caption>Notas de la clase</caption>
    <thead>
        <tr>
            <th>Alumno</th>
            <th>HTML</th>
            <th>CSS</th>
            <th>Media</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ana</td>
            <td>8</td>
            <td>7</td>
            <td>7,5</td>
        </tr>
        <tr>
            <td>Luis</td>
            <td>6</td>
            <td>9</td>
            <td>7,5</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="3">Media de la clase</td>
            <td>7,5</td>
        </tr>
    </tfoot>
</table>

AtributoEn qué se usaEfecto
colspan="n"<th> o <td>La celda ocupa n columnas.

¡Ojo! Las tablas son solo para datos. Nunca se usan para maquetar la página (distribuir bloques, cabeceras, columnas...); eso se hace con CSS (flexbox o grid).

8. Formularios

Un formulario recoge datos del usuario y los envía con action (URL de destino) y method (get para buscar, post para enviar o guardar datos). Cada campo necesita un <input> (o <select>/<textarea>) y, siempre que se pueda, una etiqueta <label> vinculada con for = id del campo.

<form action="/inscripcion" method="post">
    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre" name="nombre" required>

    <label for="email">Correo:</label>
    <input type="email" id="email" name="email" required>

    <label for="curso">Curso:</label>
    <select id="curso" name="curso">
        <option value="1">1º ESO</option>
        <option value="2">2º ESO</option>
    </select>

    <label for="obs">Observaciones:</label>
    <textarea id="obs" name="obs" rows="3"></textarea>

    <label>
        <input type="checkbox" name="acepto" required> Acepto la política
    </label>

    <button type="submit"> Enviar </button>
</form>
Tipo de inputMuestra
textCampo de texto corto.
email / url / telValidan formato automáticamente.
passwordTexto oculto.
number / rangeNúmeros y deslizador.
date / timeSelectores de fecha y hora.
checkbox / radioCasilla (varias opciones) / botón circular (una sola opción de un grupo).
fileSubida de archivos.
submit / resetEnvía el formulario / limpia los campos.

Clave: el atributo name es el que viaja al servidor (es el "nombre de la variable"). Sin name, el dato no se envía aunque el usuario lo rellene.

Checklist de buenas prácticas

  • Siempre <!DOCTYPE html>, charset y viewport.
  • Un solo <h1> por página y jerarquía de encabezados sin saltos.
  • Prefiere etiquetas semánticas (main, article...) antes que div.
  • Toda imagen con alt; todo campo con name y, si es posible, label.
  • No uses tablas para maquetar y no metas estilos en línea: CSS aparte.
  • Las etiquetas se escriben en minúscula y se cierran en el mismo orden en que se abren.
